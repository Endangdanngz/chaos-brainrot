# CHAOS BRAINROT: MUTATION ISLAND

A Roblox brainrot-collection game built with [Rojo](https://rojo.space/).
Explore a four-zone island, hunt 28 original brainrot characters, carry them
home to your base, roll mutations worth up to x35 income, survive chaos
events, steal from rival bases (or lock yours), and rebirth to unlock the
Crystal Void.

## Layout

- `src/shared/` — `Config` (all economy numbers) and `BrainrotData`
  (the character roster + procedural model builder), mapped to
  `ReplicatedStorage/Shared`.
- `src/server/` — authoritative gameplay services, mapped to
  `ServerScriptService/Server`:
  - `Main.server.luau` — bootstrap, profiles, DataStore, base assignment.
  - `WorldBuilder.server.luau` — builds the whole island procedurally.
  - `GameState.luau` — shared runtime state module.
  - `CollectionService` — wild spawns, pickup/carry, deposit.
  - `MutationService` — deposit-time mutation rolls + visuals.
  - `EconomyService` — the per-second income tick.
  - `EventService` — meteor showers, toxic rain, mutation storms,
    gravity collapse, treasure spawns.
  - `RebirthService` — rebirth + the Void portal.
  - `StealService` — base locks and player-versus-player stealing.
- `src/client/` — `UI.client.luau` (start screen, HUD, collection index,
  banners, toasts) and `Effects.client.luau` (mutation bursts, storm aura),
  mapped to `StarterPlayerScripts/Client`.

## Build

```sh
rojo build --output game.rbxl
```

The world is generated by `WorldBuilder` at server start, so the place file
stays small and every system is readable in source.
