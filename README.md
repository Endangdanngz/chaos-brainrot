CHAOS BRAINROT: MUTATION ISLAND — an original Roblox brainrot-collecting game. Explore a four-zone island (Spawn Meadow, Neon Swamp, Volcano Ashlands and the rebirth-gated Crystal Void), hunt 28 original brainrot characters, carry them home to your base where each earns cash per second, roll mutations at deposit (Gold, Neon, Radioactive, Glitched, Cosmic, Void, Celestial — up to ×35 income), survive random chaos events (meteor showers, toxic rain, mutation storms, gravity collapse, treasure spawns), steal from unlocked rival bases, and rebirth for a permanent income multiplier. Server-authoritative economy, inventory and progression, written in Luau and built with Rojo.

## How to play

1. You spawn in Spawn Meadow with an empty base and empty pockets — brainrot characters roam all four zones of the island, so start hunting right away.
2. Grab a character and carry it back to your base: the moment you deposit it, it starts earning cash for you every second.
3. Every deposit rolls a mutation — Gold, Neon, Radioactive, Glitched, Cosmic, Void and, if you are lucky, Celestial — and rarer characters with stronger mutations multiply that income, all the way up to ×35.
4. Push deeper as you earn: Neon Swamp and the Volcano Ashlands hide rarer spawns, while the Crystal Void only opens after your first rebirth.
5. Watch rival bases: if one is unlocked, sneak in, steal a character and run it home — but spend cash on your own lock dome too, because everyone else is thinking the same thing.
6. When a chaos event hits — meteor showers, toxic rain, mutation storms, gravity collapse or a treasure spawn — drop everything and react; the island pays the bold and flattens the careless.
7. Cash in your progress with a rebirth: you start over poorer but keep a permanent income multiplier, so each new run climbs faster than the last.

## Run it

```sh
# Open game.rbxl in Roblox Studio and press Play, or rebuild it from source:
rojo build default.project.json --output game.rbxl
```
